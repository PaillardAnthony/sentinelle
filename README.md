# Installation du Compagnon Sentinelle

Le compagnon est nécessaire pour permettre l'analyse complète des fichiers.

### Sur Windows

1.  Téléchargez le projet.
2.  Double-cliquez sur `install.bat` pour enregistrer le compagnon.

### Sur macOS et Linux

1.  Téléchargez le projet.
2.  Ouvrez un terminal et naviguez dans le dossier du projet.
3.  Exécutez les commandes suivantes :

    ```bash
    # Donne au script la permission d'être exécuté
    chmod +x install.sh
    
    # Lance l'installation
    ./install.sh
    ```
